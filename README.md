## 📌 Sobre o projeto

Aplicação full stack desenvolvida para simular um sistema real de cadastro e autenticação de usuários, com foco em boas práticas de backend e segurança.

Inclui operações completas de CRUD e criptografia de senha com bcrypt.


# 👤 Sistema de Cadastro de Usuários

Aplicação full stack com Node.js, Express e SQLite para cadastro e autenticação de usuários.

## 🚀 Funcionalidades
- Cadastro de usuários
- Login com validação
- Criptografia de senha com bcrypt
- Persistência com SQLite

## 🛠️ Tecnologias
- Node.js
- Express
- SQLite
- JavaScript
